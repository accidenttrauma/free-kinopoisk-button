# Free Kinopoisk

**Интегрированная в интерфейс** кнопка, которая направляет по прямой ссылке на просмотр фильма или сериала в бесплатном плеере прямо из интерфейса **[Кинопоиска](https://www.kinopoisk.ru)**.

### 🚀 Установка

1. Установи расширение **[Violentmonkey](https://violentmonkey.github.io)** / **[Tampermonkey](https://www.tampermonkey.net)** в свой браузер

2. Нажми сюда → **[Free Kinopoisk](https://raw.githubusercontent.com/accidenttrauma/free-kinopoisk-button/refs/heads/main/free-kinopoisk.user.js)**

Или добавь вручную.

### ⚙️ Настройки

Все настройки доступны через меню скрипта в панели расширения (Violentmonkey / Tampermonkey):

#### Режим отображения
| Режим | Описание |
|-------|----------|
| **Кнопка рядом** | Круглая кнопка рядом с кнопкой «Буду смотреть» |
| **Плавающая кнопка** | Перетаскиваемая кнопка поверх страницы в любом месте экрана |
| **Флажок** | Флажок в левом верхнем углу экрана |

### 🎭 Поведение
ЛКМ/Alt+Q	Открывает плеер в новой вкладке
ПКМ	Открывает плеер в текущей вкладке
Колесико Открывает плеер в фоне
